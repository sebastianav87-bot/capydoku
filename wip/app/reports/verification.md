# Capydoku v3 verification

**760/760 unique, complete pure-logic proofs, connected zones.** Campaign and both daily banks are unchanged from the immutable v2 snapshot. No powers are required for any proof.

## Independent checks

Python exhaustively enumerates all n! column permutations, separately applying zone / rock / adjacent-row constraints. The JavaScript row DFS shares neither the oracle algorithm nor the generation seed. JS checks each deduction against the unique solution. Actual daily outputs are tested for 365 consecutive local dates in both eligibility states; the additional dihedral audit covers all 8 transform cycles (5,840 date/state outputs).

## Deduction set
- **house-single**: Only candidate in a row/column/zone; remove peers.
- **shared-conflict**: A house must contain one capy; a cell conflicting with every candidate of that house is excluded. Covers intersections and common adjacency; no branching.

Levels 1–5 have one-cell zones; first forced capy requires **0 preliminary eliminations** and all five proofs use house-single only. Rocks begin at 21. Bosses are 10/20/30. See proof-effort-v1-v2-v3.md for every campaign level.

Daily uses local calendar date + rock eligibility, 365 source boards per state with 8 dihedral transforms. Streak is date-only, idempotent across both states. This is a finite deterministic bank, not infinite novelty.

The supplied v5 static visual puzzle is unique but not solvable from empty by this two-technique set. It is NOT shipped as a campaign/daily board. Its fixed Doze example is not added to the unchanged campaign rules.
